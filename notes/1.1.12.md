## Deutsch

- Hilfe → „Jetzt nach Updates suchen“ fragt sofort nach einer neuen Version und sagt auch, wenn du schon die neueste hast.
- Das Update-Band erscheint bei jedem Start wieder, solange es eine neuere Version gibt. „Später“ blendet es nur bis zum nächsten Start aus.
- Kleinere Verbesserungen an der Oberfläche.

## English

- Help → “Check for updates now” looks for a new version right away and also tells you when you already have the latest.
- The update banner comes back on every start as long as there is a newer version. “Later” only hides it until the next start.
- Small improvements to the interface.
