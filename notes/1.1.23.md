## Deutsch

### Palette direkt in der Farbzeile bearbeiten

Die Checkbox „Palette bearbeiten“ ist weg — alles geht jetzt direkt an den Farbfeldern:

- Am Ende der Farbzeile steht ein leeres Feld mit **+**. Ein Klick hängt eine neue Farbe an und öffnet gleich den Farbwähler.
- **Doppelklick** auf ein Farbfeld öffnet den Farbwähler direkt daneben, mit Hex-Feld.
- **Rechtsklick** auf ein Farbfeld: **Duplizieren** (die Kopie kommt ans Ende), **Farbe kopieren**, **Farbe einfügen** und **Farbe ändern …**; an der letzten Farbe außerdem **Entfernen**.

Ist die Palette eingebaut, landen die Änderungen wie bisher automatisch in einer eigenen Kopie. Jede Änderung lässt sich rückgängig machen.

### Farben per Hex-Wert

Unter der aktuellen Farbe gibt es jetzt ein Hex-Feld. Klick hinein, tipp z. B. `#6fa211` (das `#` darf fehlen) — liegt die Farbe schon in der Palette, wird sie gleich ausgewählt; sonst wird sie zur freien Farbe.

Ist die aktuelle Farbe frei, nimmt **+ In Palette** sie direkt als neue Nummer auf. Pixel, die schon in dieser Farbe gemalt sind, bekommen die neue Nummer mit.

## English

### Edit the palette right in the color row

The "Edit palette" checkbox is gone — everything now happens on the swatches themselves:

- At the end of the color row there is an empty **+** swatch. Clicking it adds a new color and opens the color picker right away.
- **Double-click** a swatch to open the color picker right next to it, with a hex field.
- **Right-click** a swatch: **Duplicate** (the copy goes to the end), **Copy color**, **Paste color** and **Change color …**; on the last color also **Remove**.

For a built-in palette the changes go into your own copy automatically, as before. Every change can be undone.

### Colors by hex value

Below the current color there is now a hex field. Click into it and type e.g. `#6fa211` (the `#` is optional) — if the color is already in the palette, it gets selected right away; otherwise it becomes a free color.

When the current color is free, **+ To palette** adds it as a new number directly. Pixels already painted in that color get the new number too.
