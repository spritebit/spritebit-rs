## Deutsch

### Farben per Hex-Wert

Unter der aktuellen Farbe gibt es jetzt ein Hex-Feld. Klick hinein, tipp z. B. `#6fa211` (das `#` darf fehlen) — liegt die Farbe schon in der Palette, wird sie gleich ausgewählt; sonst wird sie zur freien Farbe.

Ist die aktuelle Farbe frei, nimmt **+ In Palette** sie direkt als neue Nummer auf — ohne „Palette bearbeiten“ und ohne die letzte Farbe erst zu kopieren. Pixel, die schon in dieser Farbe gemalt sind, bekommen die neue Nummer mit.

Auch beim Bearbeiten der Palette lässt sich die Farbe einer Nummer per Hex-Wert setzen.

## English

### Colors by hex value

Below the current color there is now a hex field. Click into it and type e.g. `#6fa211` (the `#` is optional) — if the color is already in the palette, it gets selected right away; otherwise it becomes a free color.

When the current color is free, **+ To palette** adds it as a new number directly — no need for "Edit palette" or copying the last color first. Pixels already painted in that color get the new number too.

When editing the palette, a number's color can be set by hex value as well.
