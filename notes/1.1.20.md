## Deutsch

- Neues Datei-Menü, aufgebaut wie in anderen Programmen: „Neu ▸“ bietet Projekt oder Sprite an, „Öffnen …“ nimmt Projekt-, Sprite- und Aseprite-Dateien (ein Projekt öffnet sich als eigenes, ein Sprite kommt ins offene dazu). „Projekt speichern“ und „Sprite speichern ▸“ sind getrennt; einen Sprite speicherst du als spritebit-Datei (.bitty) oder als Aseprite-Datei. „Sprite hinzufügen“ heißt jetzt „Sprites aus Projekt holen …“.
- „Öffnen …“ fragt erst nach der Datei — ob vorher gespeichert werden soll, nur noch, wenn wirklich ein anderes Projekt aufgeht.

## English

- New File menu, laid out like in other programs: “New ▸” offers project or sprite, “Open …” takes project, sprite and Aseprite files (a project opens as a project of its own, a sprite joins the open one). “Save project” and “Save sprite ▸” are separate; a sprite saves as a spritebit file (.bitty) or as an Aseprite file. “Add sprite” is now “Take sprites from project …”.
- “Open …” asks for the file first — and only asks about saving when another project actually opens.
