## Deutsch

- Einzelne Sprites sichern: Datei → „Sprite speichern unter …“ legt nur den aktuellen Sprite samt Palette als .bitty-Datei ab — dieselbe Datei, die auch die Web-Version liest und schreibt.
- Sprites hinzufügen: Datei → „Sprite hinzufügen …“ holt Sprites aus einer .bitty-, Projekt- oder Web-Datei ins offene Projekt, ohne etwas zu ersetzen. Gleiche Namen bekommen eine Nummer, fremde Paletten gleichen Namens einen eigenen Namen.
- Eine .bitty-Datei öffnen fügt den Sprite ebenfalls hinzu, statt das Projekt zu ersetzen.
- Projekte heißen jetzt .sb. Alte .spritebit-Dateien öffnen sich weiter wie gewohnt.

## English

- Save single sprites: File → “Save sprite as …” stores just the current sprite and its palette as a .bitty file — the same file the web version reads and writes.
- Add sprites: File → “Add sprite …” brings sprites from a .bitty, project or web file into the open project without replacing anything. Equal names get a number, other palettes with the same name get a name of their own.
- Opening a .bitty file adds the sprite as well instead of replacing the project.
- Projects are now called .sb. Old .spritebit files still open as before.
