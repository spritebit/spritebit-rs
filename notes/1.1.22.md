## Deutsch

- Beim Start öffnet sich das zuletzt benutzte Projekt; das Startfenster kommt nur noch, wenn es keins gibt oder die Datei fehlt.
- Drückst du auf einen Sprite-Reiter, wird der Mauszeiger zur greifenden Hand — so siehst du, dass du ihn verschieben kannst.

## English

- On start, the last project opens; the start window only appears when there is none or its file is gone.
- Pressing on a sprite tab turns the pointer into a grabbing hand — so you can tell it can be moved.
